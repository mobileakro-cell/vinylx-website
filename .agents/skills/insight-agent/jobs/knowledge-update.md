# job: knowledge-update

사이트가 기사 외에 운영하는 **구조화된 지식베이스**(예: 고객 고민·성분·제품 DB, 서비스·사례 DB)를 최신 근거로 갱신한다.
무엇을 어떤 규칙으로 갱신하는지는 전부 프로필의 "지식베이스" 절에 있다. 이 파일은 공통 절차만 정한다.

## 원칙
- **이 작업은 새 인사이트 기사를 쓰지 않는다.** 기사는 daily-article 만 쓴다(발행량·금지 주제 통제를 한곳에 두기 위해). 이미 있는 기사의 오탈자·깨진 출처 수정은 허용.
- 바꿀 근거가 없으면 바꾸지 않는다. 무변경도 정상 결과다.
- 1차 자료(공식 페이지, 규제기관, 논문 원문)를 우선한다. 연구 유형·대상·기간·한계를 기록한다.
- 기존 연결을 삭제할 때는 근거를 보고에 적는다.

## 절차
1. 프로필 "지식베이스" 절에 적힌 파일들을 모두 읽고 현재 항목·id·출처를 파악한다.
2. 최근 기사들(최근 7일)과 프로필의 조사 범위에서 새 항목·변경 신호를 찾는다.
3. 프로필의 항목별 규칙대로 추가·수정한다. 다국어 필드가 있으면 모두 채운다.
4. 무결성 검사: 참조 id 가 실제로 있는지, 중복 id·중복 출처 URL 이 없는지, 모든 언어 필드가 채워졌는지.
5. 프로필 "검증 명령" 실행, `git status` 로 허용 파일만 바뀌었는지 확인.
6. DRY_RUN 이 아니면 프로필의 `knowledge-update` 커밋 형식으로 커밋·push.
7. 보고: 추가·수정·삭제한 항목과 근거 출처, 무변경이면 확인한 출처와 이유.
